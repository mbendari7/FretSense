## Read

You know the seven letter notes and that most of them are two frets apart. The single fret in
the middle of each two-fret gap holds a note too. These in-between notes are named with a
*sharp* or a *flat*.

- A **sharp** (written #) raises a note by a half step: one fret higher. F sharp (F#) is one fret
  above F.
- A **flat** (written b, or ♭) lowers a note by a half step: one fret lower. G flat (Gb) is one
  fret below G.

### One sound, two names

F# and Gb land on the same fret and sound exactly the same. Two names for one sound are called
*enharmonic* names. There are five of these in-between notes:

| Sharp name | Flat name |
|---|---|
| C# | Db |
| D# | Eb |
| F# | Gb |
| G# | Ab |
| A# | Bb |

Add them to the seven natural notes and you have all 12 notes before the pattern repeats.

There is no in-between note for E–F or B–C, because those pairs are already only a half step
apart.

### Which name do you use?

It depends on the musical context, usually the key or chord you are in. A seven-note scale such as the major scale uses each letter once. In F major, for example, the notes are F G A Bb C D E: the fourth note is written Bb,
not A#, because the scale already has an A and still needs a B of some kind.

Until you learn keys, either name is fine for finding the fret. The key will settle which name
is correct on paper.

You may also see names like E# (which sounds the same as F) or Cb (the same as B). They appear in
some keys for the same one-letter-each reason, but you won't need them for a while.

### Finding them on the neck

Find the natural note first, then move one fret. To find Eb, find E and go one fret toward the
headstock (down in pitch), or find D and go one fret toward the body (up in pitch). Both get you
to the same fret.

In these drills each in-between note is asked by one name (Db, Eb, F#, Ab, Bb). To practise both names, use the Drills screen with the "All spellings" note set.
