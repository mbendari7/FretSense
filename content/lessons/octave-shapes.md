## Read

An *interval* is the distance between two notes. A good first interval to learn is the **octave**:
the next note up (or down) with the same letter name. It is 12 half steps, so on one string it
is 12 frets away. The higher note vibrates exactly twice as fast as the lower one, which is why
the two blend so well.

Octaves are a quick way to spread what you know. If you know the notes on your low
strings, octave shapes copy that knowledge onto the higher strings.

### The shapes in standard tuning

On a bass in standard tuning, and on most guitar string pairs, neighbouring strings are a
*perfect fourth* apart (5 half steps). That gives one octave shape wherever both string pairs it crosses are a perfect fourth apart:

- **Skip one string, go two frets higher.** From a note, move two strings toward the thinner
  strings and two frets toward the body.

On a four-string bass in standard tuning: a note on string 4 (E) has its octave on string 2 (D),
two frets higher. String 3 (A) pairs with string 1 (G) the same way. For example, fret 3 on the E
string is G, and fret 5 on the D string is the G an octave above.

On a guitar in standard tuning, the G and B strings are only 4 half steps apart, so any octave
shape that crosses that pair stretches by one fret:

| From | To | Frets higher |
|---|---|---|
| String 6 (low E) | String 4 (D) | 2 |
| String 5 (A) | String 3 (G) | 2 |
| String 4 (D) | String 2 (B) | 3 |
| String 3 (G) | String 1 (high E) | 3 |

These are for standard tuning. In other tunings the shapes change, but the idea doesn't: the
octave is always 12 half steps above.

### Octaves the other way

Read any shape backwards to find the octave below: two strings toward the thicker strings and
two frets (or three, across the guitar's G and B pair) toward the headstock.

### Try it

Play a note on your lowest string, then its octave with the shape. Say the letter name for both.
Move up one fret and repeat, all the way to fret 12.
